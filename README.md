# homebrew-tap

Homebrew tap for [katamari](https://github.com/isamisushi/katamari), a
terminal diff-review tool with LSP support.

```
brew install isamisushi/tap/katamari
```

Formulae here are generated and updated automatically by
[cargo-dist](https://github.com/axodotdev/cargo-dist) on each katamari
release.
